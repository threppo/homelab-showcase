# Small, local examples

| File | Status and purpose |
| --- | --- |
| `dump-timeout.excerpt.txt` | Function excerpt from the project's backup script; inspection and stub testing only. It could invoke Docker if called directly, so do not source it manually. No backup entrypoint, credentials or configuration are included. |
| `test_dump_timeouts.py` | Runnable adaptation of the existing five-test suite. Reads only the adjacent excerpt and runs it with a locally generated fake `docker` command. Uses real timeouts shortened to seconds. |
| `network-pattern.compose.txt` | Illustrative Compose-shaped sketch with example labels and image placeholders. Shows application/database networks and a shared VPN namespace; incomplete and not deployable. |
| `backup-pipeline.md` | Illustrative reading guide to the actual backup stages and failure handling; no executable commands. |
| `test_sqlite_wal.py` | Runnable synthetic demonstration newly generated by Codex for this export. Uses invented data and Python SQLite inside temporary storage. Demonstrates the failure and generation separation; does not test the operational restore helper. |

Run on Linux with Python 3 (including SQLite), Bash, GNU `timeout`, `/bin/sh` and
`sleep` on PATH. All local file dependencies are included. No Docker installation,
package download, cloud account, secrets or repository checkout is required.

From this export folder, run:

```bash
python3 examples/test_sqlite_wal.py -v
python3 examples/test_dump_timeouts.py -v
bash -n examples/dump-timeout.excerpt.txt
```

Both tests create and clean up only their own temporary fixtures. The timeout
suite intentionally launches and terminates local child processes and checks
failure statuses. It does not run database dumps or talk to a container daemon.
No examples modify services, networking or real application data. The excerpt
is stored as text to discourage operational use. No deployment instructions
or production recovery scripts are included. Networking and pipeline sketches are
for explanation only and are not executable examples.

The original timeout suite's source-loading block is adapted for this export;
the five test methods are retained. See [attribution](../SOURCES.md) and
[validation](../validation.md) for provenance and limits.
